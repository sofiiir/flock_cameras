# Exploring Flock Camera Distribution

### Background
Flock cameras are a brand of Automate License Plate Readers (ALPRs) that are being installed throughout the US. ALPRs have been promoted as a tool to combat crime, however in reality they pose privacy risks as they track peoples movements sharing it nationally with participating agencies. ALPRs give users unfounded access to constant data of peoples whereabouts.  Misuse of ALPR data is reported with some of the most malicious uses being police stalking ex-partners.

A movement to remove ALPRs called [DeFlock](https://deflock.org/) is mapping ALPR locations nationwide. This repository explores the ALPR location data.
